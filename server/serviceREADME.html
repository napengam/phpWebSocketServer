WebSocket Service

Create the systemd service file:

use

[Unit]
Description=WebSocket Service
After=network.target

[Service]
Type=exec
User=www-data
WorkingDirectory=/var/www/html/phpWebSocketServer
ExecStart=/usr/bin/php /var/www/html/phpWebSocketServer/server/runSocketServer.php
Restart=always
RestartSec=5

[Install]
WantedBy=multi-user.target
        
sudo nano /etc/systemd/system/phpWebSocketServer.service

Then reload, enable, and start the service:

sudo systemctl daemon-reload
sudo systemctl enable --now phpWebSocketServer.service

Check its status and logs:

sudo systemctl status phpWebSocketServer.service
sudo journalctl -u phpWebSocketServer.service -f
