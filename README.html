webSocketServer Documentation

PHP 8+ RFC 6455

High-performance, non-blocking WebSocket server implemented in native PHP stream sockets using the RFC_6455 trait. Supports direct TLS termination, reverse-proxy pass-through, ping/pong keepalives, and multi-resource routing.

Features

  • Full RFC 6455 compliant handshake & framing via trait.
  • Dual SSL/TLS modes: Direct PHP crypto termination or TCP pass-through (Nginx/HAProxy).
  • Resource handler architecture for endpoint routing.
  • Built-in IP rate limiting, origin checks, and auto ping/pong eviction.

Resource Handler Interface

Any application registered with registerResource() must implement these 5 methods:

MethodDescription
registerServerMethods($server)Stores the server instance reference.
onOpen($socketId)Triggered when a new WebSocket handshake completes.
onData($socketId, $message)Triggered when a decoded frame payload is received.
onClose($socketId)Triggered when a connection terminates.
onError($socketId, $message)Triggered on stream or protocol errors.

    public function onData($socketId, $message): void {
        if (empty($message)) {
            return;
        }
        $this->server->broadCast($socketId, $message);
    }

    public function onClose($socketId): void {
        $this->server->Log("Client #{$socketId} disconnected.");
    }

    public function onError($socketId, $message): void {
        $this->server->Log("Error on #{$socketId}: {$message}");
    }
}

JavaScript Client

const ws = new WebSocket("ws://localhost:8080/chat");

ws.onopen = () => {
    ws.send(JSON.stringify({ type: "greeting", payload: "Hello" }));
};

ws.onmessage = (event) => {
    const data = JSON.parse(event.data);
    if (data.opcode === 'ready' || data.opcode === 'next') {
        return;
    }
    console.log("Received:", data);
};

ws.onclose = () => {
    console.log("Disconnected");
};
